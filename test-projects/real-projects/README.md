# Test projects

The four open-source projects used to validate the framework are not stored in this repo.
Clone them into this folder to reproduce the results:

```bash
git clone https://github.com/spring-guides/gs-spring-boot
git clone https://github.com/spring-petclinic/spring-petclinic-microservices
git clone https://github.com/microservices-demo/microservices-demo sock-shop
git clone https://github.com/dotnet-architecture/eShopOnContainers
```
