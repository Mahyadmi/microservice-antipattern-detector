Cloud-Native Detection of Microservice Anti-Patterns

Using static analysis tools and serverless architectures

MSc Software Engineering dissertation · Mahyad Mirzabagheri · Staffordshire University, 2025 · Source code

Microservice systems often contain anti-patterns: design mistakes such as services sharing one database or depending on each other so tightly that they must be deployed together. This project combines the ideas of three analysis tools (SonarQube, Roslyn and ArchUnit) in one cloud-native pipeline that finds these problems, merges duplicate findings and produces a single report. The serverless AWS design was prototyped locally with Docker and tested on four open-source projects.
